# Public Restaurant and Menu API (Phase 5.1)

These read-only routes accept guest requests without a session, `Origin`, or CSRF token. The path slug is trimmed and lowercased before lookup. Only an active Restaurant is visible; missing and suspended restaurants return the same `404 { "error": "Not found" }`. Invalid slugs or query values return `400 { "error": "Invalid public request" }`.

- `GET /api/public/restaurants/:slug` returns `{ "restaurant": { ... } }`. The public Restaurant DTO includes `name`, `slug`, `description`, `logoUrl`, `currency`, `phone`, `contactEmail`, `address`, `openingHours`, `deliverySettings` (`deliveryFee`, `minimumOrder`, `estimatedDeliveryTime`, `deliveryAvailable`), `socialLinks` (`facebook`, `instagram`, `whatsapp`), and `branding` (`brandName`, `primaryColor`). Optional values are `null` when absent.
- `GET /api/public/restaurants/:slug/categories` returns `{ "categories": [ ... ], "pagination": { "page": 1, "limit": 50, "total": 0, "hasNext": false } }`. A category contains `id`, `name`, `slug`, `description`, `imageUrl`, and `sortOrder`. Only active categories of the resolved restaurant appear. Sort order is `sortOrder`, then `id`, both ascending.
- `GET /api/public/restaurants/:slug/products` returns `{ "currency": "EGP", "products": [ ... ], "pagination": { "page": 1, "limit": 20, "total": 0, "hasNext": false } }`. A product contains `id`, `categoryId`, `name`, `slug`, `description`, `price`, `oldPrice`, `imageUrl`, `images`, `isFeatured`, `preparationTime`, and `calories`. Stored prices are returned unchanged; `currency` comes from the resolved restaurant. Products must be available and reference an active category in that same restaurant. Orphans and foreign-category products are excluded before pagination and counting.

Category and product listings accept `page` (1-1000) and `limit` (1-100). Products also accept `categoryId` (24 hexadecimal ObjectId characters), `isFeatured` (`true` or `false`), and `sort` (`name`, `-name`, `price`, `-price`, `createdAt`, `-createdAt`; default `name`). All sorts use `id` ascending to break ties. Unknown parameters, duplicate parameter values, and MongoDB operators are rejected. A page beyond the last item returns an empty array and the same total.

Public responses send `Access-Control-Allow-Origin: *` without `Access-Control-Allow-Credentials`. This allows read-only storefronts on different domains without adding them to `AUTH_TRUSTED_ORIGINS`. Owner routes retain their credentialed CORS, trusted-Origin, session, and CSRF protections. No public write endpoint is part of this phase.

The current frontend types include some flat delivery fields and a product `image` field. A future frontend adapter can map this API's schema-backed nested delivery settings and `imageUrl`; the frontend is unchanged here.
